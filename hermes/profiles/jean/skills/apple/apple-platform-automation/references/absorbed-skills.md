# Absorbed Apple Skills

This umbrella absorbed these formerly separate skills:

- `apple-notes`: `memo` CLI for create/search/edit Apple Notes.
- `apple-reminders`: `remindctl` CLI for add/list/complete reminders and date format cautions.
- `imessage`: `imsg` CLI for SMS/iMessage send/read with recipient disambiguation.
- `findmy`: Find My/AirTag location via AppleScript, screenshots, or Peekaboo UI automation, with precision caveats.
- `macos-computer-use`: capture → act → recapture GUI workflow for macOS-only surfaces.

The archived original packages remain recoverable under the skill archive if exact historical wording is needed.
