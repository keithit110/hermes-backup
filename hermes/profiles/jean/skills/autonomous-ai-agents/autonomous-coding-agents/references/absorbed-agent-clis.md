# Absorbed Autonomous Coding Agent Skills

This umbrella absorbed these formerly separate skills:

- `claude-code`: Claude Code CLI delegation, including PTY handling for interactive sessions.
- `codex`: Codex CLI one-shot/background usage, PR review, and worktree-based parallel issue fixing.
- `opencode`: OpenCode CLI delegation, binary resolution, one-shot tasks, and interactive sessions.

The umbrella intentionally focuses on orchestration invariants: self-contained prompts, isolation, background/PTY discipline, and parent-session verification.
